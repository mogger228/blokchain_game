# Review verdict: FAIL

Объект: `docs/plan/telegram-bot.md`, первая редакция.

## reviewer-correctness: FAIL

- Не был запланирован обязательный вызов `initialize()` перед polling и командами.
- Для сохраняемого CLI `send` отсутствовала отдельная сервисная операция.
- Запрет зарегистрированного получателя `@system` не следовал из дизайна.
- Telegram-поиск по ID не покрывал невалидный ввод, отсутствие блока, генезис и полный формат результата.

## reviewer-idempotency: FAIL

- Receipt связывал action key только с блоком, но не с actor/type/параметрами.
- Старый callback мог применить изменённый payload из общего `user_data`.
- CLI append оставался вне явно описанной атомарной операции.
- Удаление новых таблиц при downgrade уничтожало регистрации и receipts.
- План явно не запрещал commit внутри `_insert_block` составной транзакции.
- Не хватало конкурентных тестов регистрации, разных переводов, init, CLI ↔ bot.
- Список игроков и цепочка могли читаться из разных snapshot.
- Уже зарегистрированный игрок без текущего Telegram username мог быть ошибочно заблокирован.

## reviewer-compat: FAIL

- API сервиса не обеспечивал прежнюю семантику CLI `send`.
- Описанный destructive downgrade терял новые данные.
- Изменение разрешения относительного пути `chain.db` могло молча открыть другую БД.
- Не был зафиксирован поддерживаемый диапазон Python.
- В текущей среде отсутствует Python/SQLite, поэтому Gate 0 и финальный Quick start пока технически невыполнимы.

## Исправления перед повторным ревью

- Добавлены `initialize()` и атомарный `create_trusted_transaction()`.
- Receipt расширен actor/type/fingerprint; авторизация выполняется до replay.
- Callback содержит action key и сверяется с неизменяемым active intent.
- Rollback к старому коду оставляет аддитивные таблицы; destructive downgrade не поддерживается без восстановления полной копии.
- Зафиксированы `_insert_block` без commit, единая граница транзакции и расширенная concurrency-матрица.
- Добавлены snapshot-чтение, поведение существующего игрока без текущего username и полные ID-search cases.
- Добавлена legacy-safe стратегия пути БД и контракт CPython 3.10–3.15 / `python-telegram-bot==22.8`.
