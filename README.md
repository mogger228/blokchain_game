# ⛓️ Blockchain Game

Простая Telegram-игра на Python: получай игровые монеты, переводи их другим игрокам и смотри, как транзакции складываются в блокчейн.

**Стартовый баланс — 100 игровых долларов.** Каждый перевод сохраняется в SQLite как блок с хешем предыдущего блока.

> Это учебный проект. Игровые монеты не имеют реальной стоимости.

## Что умеет бот

| Для игроков | Для администратора |
| --- | --- |
| Регистрация по Telegram username | Доступ по заданному Telegram ID |
| Однократное получение стартовых $100 | Список игроков и их балансов |
| Переводы зарегистрированным игрокам | Начисление монет выбранному игроку |
| Просмотр своего баланса | Быстрые суммы: $10, $50, $100 |
| Поиск транзакции по ID | Ввод произвольной суммы |
| Просмотр и проверка цепочки | Подтверждение начисления перед записью |

## Быстрый старт

Понадобятся **Python 3.10–3.15**, Telegram и токен бота от [@BotFather](https://t.me/BotFather). Используется `python-telegram-bot==22.8`.

### 1. Скачайте проект

```bash
git clone https://github.com/mogger228/blokchain_game.git
cd blokchain_game
```

### 2. Установите зависимости

**Windows · PowerShell**

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

**Linux / macOS**

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

### 3. Настройте Telegram

1. Откройте [@BotFather](https://t.me/BotFather), отправьте `/newbot` и получите токен.
2. Узнайте числовой Telegram ID пользователя, который станет администратором.
3. Создайте файл `.env` рядом с `bot.py` (можно скопировать `.env.example`) и укажите токен и ID:

```dotenv
TELEGRAM_BOT_TOKEN=ТОКЕН_ОТ_BOTFATHER
TELEGRAM_ADMIN_ID=123456789
```

Число `123456789` замените своим Telegram ID. Затем запустите бота:

**Windows · PowerShell**

```powershell
.\.venv\Scripts\python.exe bot.py
```

**Linux / macOS**

```bash
.venv/bin/python bot.py
```

Откройте личный чат с ботом и отправьте `/start`.

> Файл `.env` автоматически загружается из каталога проекта. Переменные окружения имеют приоритет над `.env`. Настоящий токен храните локально и не добавляйте в Git.

## Как играть

При первом `/start` бот регистрирует ваш username и начисляет **$100 ровно один раз**. Для первой регистрации username должен быть установлен в настройках Telegram.

Чтобы отправить монеты:

1. Нажмите **«Создать транзакцию»**.
2. Введите username зарегистрированного получателя.
3. Укажите сумму.
4. Добавьте сообщение получателю (до 1000 символов) или нажмите **«Без сообщения»**.
5. Проверьте сумму, получателя и сообщение, затем подтвердите перевод.

При зачислении бот отправляет получателю уведомление: от кого пришли деньги, сумма,
ID транзакции и сообщение отправителя, если оно добавлено. Уведомления приходят также
при начислении администратором. При поиске по ID сообщение к переводу видно только
администратору в личном чате с ботом; остальные пользователи видят данные блока без сообщения.

Если временно нет связи с Telegram, уведомление остаётся в очереди SQLite и отправляется
позже, в том числе после перезапуска. Если пользователь заблокировал бота, зачисление
сохраняется, а невозможность доставки записывается в лог. При потере ответа Telegram
возможен повтор уведомления с тем же ID; деньги повторно не начисляются.

В меню также доступны баланс, поиск транзакции по ID, просмотр блоков и проверка целостности цепочки. Команда `/cancel` отменяет незавершённое действие.

Игровое имя фиксируется при регистрации. Если вы позже измените или удалите username в Telegram, доступ сохранится по вашему Telegram ID.

### Админ-панель

Пользователь с ID из `TELEGRAM_ADMIN_ID` после регистрации увидит кнопку **«Админ-панель»**.

- **«Пользователи и балансы»** — постраничный список зарегистрированных игроков.
- **«Начислить»** — выбор игрока, суммы и подтверждение операции.

Начисления записываются в цепочку как `system → @username`. Личный игровой баланс администратора при этом не уменьшается.

## Проверка установки

**Windows · PowerShell**

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe scripts\smoke.py
```

**Linux / macOS**

```bash
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python scripts/smoke.py
```

Ожидаемый результат: тесты завершаются с `OK`, а smoke выводит:

```text
SMOKE PASS: registrations=2, balances=75/175, transfer_id=3, grant_id=4, chain=valid
```

Smoke проверяет регистрацию двух игроков, перевод, админское начисление, балансы, поиск по ID и целостность цепочки. Он использует временную базу.

## Командный интерфейс

Проект можно использовать и без Telegram. Пример для Windows:

```powershell
.\.venv\Scripts\python.exe main.py init
.\.venv\Scripts\python.exe main.py send --from system --to Alice --amount 100
.\.venv\Scripts\python.exe main.py send --from Alice --to Bob --amount 25
.\.venv\Scripts\python.exe main.py balance --user Alice
.\.venv\Scripts\python.exe main.py transaction --id 1
.\.venv\Scripts\python.exe main.py chain
.\.venv\Scripts\python.exe main.py validate
```

На Linux/macOS замените `.\.venv\Scripts\python.exe` на `.venv/bin/python`.

Только `init` создаёт отсутствующую базу. Остальные команды требуют существующую БД. CLI предназначен для владельца проекта и позволяет вручную указать отправителя.

## Настройки и хранение данных

При запуске бот автоматически создаёт `logs/bot.log` в каталоге проекта. Логи выводятся и в терминал, и в файл в UTF-8: запуск, остановка, ошибки конфигурации и ошибки работы со стеком вызовов. При достижении 5 МБ файл ротируется; сохраняются до трёх предыдущих файлов (`bot.log.1`–`bot.log.3`). Каталог `logs/` исключён из Git.

Для подключения к Telegram бот ждёт до 15 секунд и при сбое подключения делает до двух повторов. Ожидание ответа и запись запроса — до 30 секунд. Сбои чтения или записи запроса автоматически не повторяются: Telegram мог уже выполнить действие. Сетевые сбои записываются как предупреждения. Если ответ не пришёл, повторите последнее действие или отправьте `/cancel` и начните диалог заново. При постоянных сбоях проверьте доступ к `api.telegram.org` и настройки сети.

| Переменная | Назначение |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | Токен от BotFather; обязателен для бота |
| `TELEGRAM_ADMIN_ID` | Числовой ID единственного администратора |
| `BLOCKCHAIN_DB_PATH` | Необязательный путь к SQLite-базе |

По умолчанию база `chain.db` находится рядом с кодом проекта. Чтобы выбрать другой путь в PowerShell:

```powershell
$env:BLOCKCHAIN_DB_PATH = "C:\data\telegram-game.db"
```

Если при запуске из другого каталога найден отдельный `chain.db`, приложение попросит явно указать нужный путь через `BLOCKCHAIN_DB_PATH`.

### Совместимость со старой версией

Бот добавляет таблицы `players`, `processed_actions` и `money_notifications`, сохраняя существующие блоки и формат их хешей. При возврате к старому коду оставьте дополнительные таблицы: они хранят регистрации, защиту от повторных действий, сообщения к переводам и очередь уведомлений. Сообщения хранятся отдельно от хеша блока. Старые переводы при обновлении не рассылаются. Для полного возврата базы используйте резервную копию.
